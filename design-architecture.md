# Scholars Pride Preview 4 — design and information architecture

## Direction

Preview 4 preserves the source preview's premium editorial rhythm: image-led hero, compact evidence bar, disciplined grid, asymmetrical storytelling, dark institutional panels and focused motion. The identity is now wholly Scholars Pride, using its official logo, logo-derived blue/red tokens and only authentic school-owned photography from the current public website.

## Homepage progression

1. Compact utility bar, six-part accessible navigation and visit CTA.
2. School discovery hero with verified school facts.
3. Four proposed learning-stage routes, explicitly awaiting grade-band confirmation.
4. Legacy, school values and academic positioning.
5. Editorial mosaic for academics, sport, music/dance and activities.
6. Campus facilities with an honest photo-gallery fallback until real 360° media exists.
7. Year-labelled results and updates.
8. Split admissions and parent-resource pathway.
9. Contact-rich footer and mandatory disclosure access.

## Interaction and accessibility

Desktop mega menus open on hover intent, focus and click, with delayed pointer exit and Escape dismissal. Mobile uses an accordion drawer with persistent resource, call and visit actions. Search is functional for high-priority tasks. Focus styles, reduced-motion support, semantic landmarks, responsive typography and readable contrast are built in.
